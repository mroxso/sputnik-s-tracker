# Security Policy

This is a static site with no backend and no user accounts. It still matters if, for example, mission data or a dependency could inject script into the page.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately via [GitHub security advisories](https://github.com/mroxso/sputnik-s-tracker/security/advisories/new).

We aim to respond within a week. Only the latest version on `main` is supported.
